# RECHORDS — магазин виниловых пластинок

Учебный проект: полноценный сайт магазина винила с AJAX на Fetch API, сервером Node.js (Express) и базой данных SQLite.

## Запуск

```bash
npm install
npm start
```

Сайт будет доступен по адресу http://localhost:3000

## Стек

- **Frontend:** HTML5, CSS3 (адаптивная вёрстка), JavaScript (Fetch API, AJAX)
- **Backend:** Node.js + Express
- **БД:** SQLite (better-sqlite3)
- **Контроль версий:** Git + GitHub

## Страницы

| Страница | Файл | Описание |
|---|---|---|
| Главная | `public/index.html` | Hero, новинки, хиты, жанры, редакция, подписка |
| Каталог | `public/catalog.html` | AJAX-фильтры: жанр, цена, формат, скидки, поиск, сортировка |
| Страница товара | `public/product.html` | Обложка, трек-лист, отзывы, похожие пластинки, покупка |
| О нас | `public/about.html` | История, статистика, ценности |
| Контакты | `public/contacts.html` | Форма связи, карта, FAQ-аккордеон |

## API (все запросы через Fetch API)

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/api/albums` | Список пластинок: `search`, `genre`, `status`, `format`, `sort`, `minPrice`, `maxPrice`, `discount`, `limit`, `offset` |
| GET | `/api/albums/:slug` | Пластинка: трек-лист, отзывы, похожие |
| POST | `/api/albums/:slug/reviews` | Добавить отзыв |
| GET | `/api/genres` | Жанры с количеством пластинок |
| GET | `/api/categories` | Категории каталога |
| GET | `/api/faqs` | Частые вопросы |
| GET | `/api/stats` | Статистика для страницы «О нас» |
| POST | `/api/subscribe` | Подписка на рассылку |
| POST | `/api/contacts` | Сообщение из формы обратной связи |
| POST | `/api/orders` | Оформление заказа (списывает остатки) |

## Замена обложек на свои

По умолчанию используются сгенерированные плейсхолдеры `public/img/albums/1.jpg`, `2.jpg`, … `44.jpg`
(номер = артикулу пластинки). Чтобы поставить свои фото:

1. Посмотрите соответствие «номер → альбом» в файле `public/img/albums/manifest.json`.
2. Замените нужные `N.jpg` своими изображениями (JPG, рекомендуется квадрат 600×600).
3. Если файл удалён или не открывается, сайт автоматически подставит векторную обложку из `public/img/covers/`.

Крутящаяся пластинка в hero-секции главной страницы — файл `public/plastinka.png`.
Просто замените его своей картинкой с тем же именем (лучше квадратной, с прозрачным или нейтральным фоном).

Перегенерировать плейсхолдеры:

```bash
npm run covers
```

## Возможности

- Корзина на localStorage с выезжающей панелью
- Оформление заказа через AJAX (без перезагрузки страницы)
- Живой поиск и фильтры в каталоге без перезагрузки
- Отзывы и рейтинги, обновляющиеся после отправки
- Нумерованные обложки-плейсхолдеры для замены на свои
- Адаптивная вёрстка: мобильные, планшеты, десктоп
